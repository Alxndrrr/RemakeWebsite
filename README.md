# Remake website

Static placeholder website for `getremake.app`.

## Files
- `index.html` — landing page with SEO metadata and app schema.
- `styles.css` — visual styling.
- `robots.txt` — allows search engines to crawl the site.
- `sitemap.xml` — points search engines to the homepage.
- `assets/remake-app-icon.png` — copied from the iOS app icon.
- `assets/favicon.png` — browser/app icon.
- `assets/social-preview.png` — image used when sharing the page.

## Deploy
Use this folder as the source for GitHub Pages or copy its contents to a dedicated website repository.

Set the custom domain to:

```text
getremake.app
```

The SEO/social URLs currently point to the GitHub Pages repository URL. When `getremake.app` is live, update `index.html`, `robots.txt`, and `sitemap.xml` to use the custom domain.
